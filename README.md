# Bảo Duy & Uyên Phương — Wedding Invitation

Static wedding invitation built with plain HTML, CSS and JavaScript.

## Run locally

Just open `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload/push all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the public URL.

No Node.js, build step, database or paid hosting is required.

## Customize

Most wedding details are inside `index.html`.

- Names
- Date/time
- Venue
- Address
- Google Maps link
- Text

The countdown target is in `script.js`.
